# Paneful

X(트위터)를 여러 계정으로 한 창에서 쓰는 데스크톱 앱. 패널을 나란히 띄우고 패널마다 다른 계정으로 로그인해 둔다. 브라우저 프로필을 여러 개 띄우거나 계정을 계속 바꿀 필요가 없다.

- 패널마다 로그인이 완전히 따로 저장되고, 껐다 켜도 유지된다
- 패널마다 새 알림·쪽지 수를 보여 주고, 새로 오면 시스템 알림을 띄운다 (설정에서 끔)
- 보던 게시물을 다른 계정 패널에서 바로 연다
- 이미지·동영상을 원본 화질로 저장한다
- 게시물 여러 개를 PNG 한 장으로 캡쳐한다. 이름·프로필 사진을 가린 익명본도 된다
- 패널마다 글자 크기를 따로 맞춘다
- X 단축키를 다른 키로 바꾸거나 끈다
- 트레이로 숨기면 재생 중인 영상·소리가 멈춘다

> X Corp.과 무관한 비공식 앱이다. 앱은 어떤 데이터도 수집·전송하지 않는다. 비밀번호는 앱이 다루지 않고, 로그인은 패널 안의 x.com에서 직접 한다.

## 받기

[Releases](https://github.com/Machrie/paneful/releases)에서 최신 버전을 받는다.

| OS | 파일 | 지원 버전 |
|---|---|---|
| Windows | `Paneful_<버전>_x64-setup.exe` (설치)<br>`Paneful_<버전>_x64-portable.zip` (포터블) | 10, 11 (64비트) |
| macOS | `Paneful_<버전>_universal.dmg` | 14 Sonoma 이상 (Apple Silicon, Intel) |

유료 코드 서명을 안 한 앱이라 처음 열 때 경고가 뜬다. 아래대로 허용하면 된다.

### Windows

1. 설치 파일을 실행한다
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보** → **실행**

관리자 권한은 필요 없다. Windows 11의 **스마트 앱 컨트롤**이 켜져 있으면 우회 버튼 없이 막힌다.

<details>
<summary>포터블(zip)</summary>

- 압축을 풀고 `Paneful.exe`를 실행한다. 바탕화면, 문서, USB처럼 쓰기 되는 곳에 푼다(`Program Files`는 안 됨)
- 설정과 로그인 정보는 exe 옆 `data` 폴더에 저장된다. 옆의 `portable.txt`를 지우면 설치판처럼 AppData를 쓴다
- 폴더째 다른 PC로 옮기면 설정은 따라가지만 로그인은 풀린다. 패널마다 다시 로그인하면 된다
- **`data` 폴더엔 로그인 쿠키가 들어 있다.** 남에게 넘기거나 잃어버리지 않게 조심한다
- 처음 켤 때 `data`가 비어 있으면 예전 설치판·포터블의 데이터를 복사해 온다
- WebView2 런타임이 필요하다. 켜자마자 꺼지면 [WebView2 런타임](https://developer.microsoft.com/microsoft-edge/webview2/)을 설치한다

</details>

### macOS

터미널에서 아래 한 줄을 붙여넣는 게 제일 편하다. 최신 버전을 받아 `응용 프로그램`에 넣고 실행까지 한다. 브라우저를 안 거쳐서 경고창이 안 뜬다. 업데이트도 같은 줄이다(켜져 있으면 끄고 바꾼 뒤 다시 켬, 설정·로그인은 그대로).

```sh
curl -fsSL https://raw.githubusercontent.com/Machrie/paneful/main/scripts/install-macos.sh | bash
```

하는 일은 [`scripts/install-macos.sh`](scripts/install-macos.sh)에 다 있다.

<details>
<summary>dmg를 직접 받아서 설치</summary>

1. `.dmg`를 열고 `Paneful`을 `응용 프로그램` 폴더로 끌어 넣는다
2. 실행해서 경고창이 뜨면 **완료**로 닫는다
3. 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "Paneful … 차단되었습니다" 옆 **그래도 열기** → 암호 입력 → **그래도 열기**
   - macOS 14는 Finder에서 우클릭 → **열기** → **열기**로도 된다

이 앱은 Apple 공증을 안 받아서, 브라우저로 새로 받을 때마다(업데이트 포함) 경고창이 다시 뜬다. `응용 프로그램`에 넣은 뒤 터미널에서 아래 한 줄을 치면 경고 없이 바로 열린다. "손상되었기 때문에 열 수 없습니다"가 뜰 때도 이걸로 된다.

```sh
xattr -dr com.apple.quarantine /Applications/Paneful.app
```

</details>

## 사용법

1. 처음 열면 패널 두 개가 뜬다. 패널마다 다른 계정으로 로그인한다
2. 패널 사이 틈을 끌어 폭을 맞춘다
3. 맨 위 얇은 줄을 클릭하거나 `Ctrl+Shift+H`를 누르면 상단 바가 열린다. 여기서 계정 추가(**＋ 계정**), 패널 새로고침·삭제, 캡쳐, 설정을 한다

macOS에선 `Ctrl` 대신 `⌘`. 패널에서 `Ctrl+/`를 누르면 단축키 목록, `Ctrl+,`는 설정이 열린다.

### 단축키

| 키 | 동작 |
|---|---|
| `Ctrl+1` ~ `Ctrl+9` | N번째 패널로 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 다음 / 이전 패널 (맥도 `Ctrl`) |
| `Ctrl+O` | 복사한 X 링크를 지금 패널에서 열기 |
| `Ctrl+Shift+O` | 게시물을 다른 패널에서 열기 |
| `Ctrl+Shift+F` | 패널 하나만 크게 보기 / 되돌리기 |
| `Ctrl+Shift+S` | 게시물 캡쳐 |
| `Ctrl+Shift+H` | 상단 바 보이기 / 숨기기 |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | 패널 배율 키우기 / 줄이기 / 100% |
| `Ctrl+R` | 패널 새로고침 |
| `Ctrl+Alt+X` (맥 `⌘⌥X`) | 창 숨기기 / 불러오기 (다른 앱을 보고 있어도 됨) |
| `Ctrl+/` / `Ctrl+,` | 단축키 목록 / 설정 |

`Ctrl+1~9` 말고는 설정에서 바꾸거나 끌 수 있다. X 자체 단축키(`j`/`k`, `l` 등)도 그대로 먹고, 설정의 **X 단축키**에서 바꾸거나 끈다.

### 링크로 열기

패널엔 주소창이 없다. X 링크를 복사하고 패널에서 `Ctrl+O`를 누르면 "이동할까?"가 뜬다. `twitter.com`, `fxtwitter.com`, `vxtwitter.com` 링크도 되고 추적 파라미터는 떼고 연다. 키는 설정에서 바꿀 수 있다. `Ctrl+V`로 바꾸면 입력창 밖에서만 먹는다(입력창에선 그냥 붙여넣기). x.com 밖 링크는 클릭하면 기본 브라우저에서 열린다.

### 다른 패널에서 열기

부계정으로 좋아요·재게시할 때 쓴다. `Ctrl+Shift+O`를 누르고 게시물을 클릭하면 다른 패널에서 열린다. 패널이 셋 이상이면 열 패널을 고른다. 지금 보는 페이지를 통째로 보내려면 `Enter`, 취소는 `Esc`.

### 알림 숫자

패널마다 새 알림·안 읽은 쪽지 수가 상단 바 탭에 뜬다. 하나라도 있으면 트레이·작업 표시줄(맥은 Dock) 아이콘에 표시가 붙는다. 설정의 **알림 표시**로 끈다.

### 패널 배율

패널마다 글자 크기를 따로 맞추고 기억한다. `Ctrl+=` / `Ctrl+-` / `Ctrl+0`, 또는 `Ctrl`+휠(맥은 기본 꺼짐, 설정에서 켬). 100%가 아니면 상단 바 탭에 **90%** 같은 표시가 붙고, 누르면 100%로 돌아간다.

### 이미지·동영상 원본 저장

미디어에 마우스를 올리면 오른쪽 위에 **⤓ 원본** 버튼이 뜬다. 누르면 원본 화질로 `다운로드/Paneful`에 저장된다(설정에서 폴더 변경). 동영상에서 "새로고침 후 다시"가 뜨면 패널을 새로 고치고 다시 누른다.

### 게시물 캡쳐

게시물 여러 개를 X 화면 그대로 PNG 한 장으로 만든다.

1. `Ctrl+Shift+S` 또는 상단 바 **카메라** 버튼
2. 첫 게시물 클릭 → 스크롤해서 마지막 게시물 클릭 (하나만 찍으려면 `Enter`)
3. 앱이 알아서 스크롤하며 찍는다. 끝나면 미리보기가 뜬다
4. **익명화** 체크로 익명본/원본을 고르고 **복사**나 **PNG 저장**

익명화는 사람마다 `익명1`, `익명2`로 이름·아이디·멘션·프로필 사진을 가린다. 사진·동영상 속 얼굴이나 글 내용은 못 가리니 공유 전에 직접 확인한다. 한 번에 150개까지.

### 트레이로 숨기기

상단 바의 **눈 가림** 버튼이나 `Ctrl+Alt+X`로 창을 숨긴다. 숨기는 순간 재생 중인 영상·소리가 멈춘다. 같은 단축키나 트레이(맥은 메뉴 막대) 아이콘으로 다시 띄운다. 창의 닫기 버튼은 앱을 끈다.

### 설정

탭 다섯 개로 나뉜다. 바꾸면 바로 저장된다.

- **일반**: 패널 이름·순서, 저장 폴더, 알림 표시, 휠 배율
- **단축키**: Paneful 단축키
- **X 단축키**: X 자체 단축키 바꾸기·끄기
- **업데이트**: 새 버전 확인, X 화면 규칙
- **고급**: 패널별 메모리 사용량, 포터블 데이터 폴더

### 업데이트

새 버전이 나오면 상단 바와 트레이 메뉴에 알림이 뜬다.

- **macOS**: **업데이트**를 누르면 새 버전을 받아서 앱을 끄고, 바꾸고, 다시 켠다. 경고창은 안 뜨고 설정·로그인은 그대로다. `응용 프로그램` 폴더의 앱으로 실행할 때만 된다. 안 되면 [설치할 때 쓴 터미널 한 줄](#macos)을 다시 붙여넣으면 된다(설정의 업데이트 탭에 복사 버튼 있음).
- **Windows**: **받기**를 누르면 릴리스 페이지가 열린다. 받아서 설치하는 건 직접 한다.

X가 화면을 바꿔서 캡쳐·알림 숫자 같은 기능이 깨지면, 앱 업데이트 없이 고친 규칙을 알아서 받아 온다. 받는 건 짧은 문자열뿐이고 코드는 실행되지 않는다.

## 제거

앱에서 계정을 먼저 삭제(탭의 휴지통)하면 로그인 정보도 같이 지워진다.

- **Windows**: 설정 → 앱에서 Paneful 제거. 남은 설정은 `%APPDATA%\dev.machrie.paneful`, `%LOCALAPPDATA%\dev.machrie.paneful`. 포터블은 폴더째 지운다
- **macOS**: `Paneful`을 휴지통으로. 남은 설정은 `~/Library/Application Support/dev.machrie.paneful`, `~/Library/Logs/dev.machrie.paneful`

## 문제가 생기면

[Issues](https://github.com/Machrie/paneful/issues)에 OS 버전, 증상, 가능하면 로그를 올려 달라.

- Windows 로그: `%LOCALAPPDATA%\dev.machrie.paneful\logs`
- macOS 로그: `~/Library/Logs/dev.machrie.paneful`

빌드 방법과 구조는 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
