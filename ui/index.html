X 활성 패널에서

X 단축키는 색 표시된 활성 패널에서 동작 · 패널을 클릭해도 전환 · 닫기 Esc

설정

패널

이름은 칸에서 고치고 Enter. 화살표로 순서 바꾸기 (Ctrl+1~9는 화면 순서를 따라감).

저장 폴더

이미지·동영상 다운과 게시물 캡쳐 PNG가 저장되는 곳 · 지금은 기본 폴더

포터블 데이터

설정·로그·로그인 데이터가 저장되는 exe 옆 폴더. 다른 PC로 옮기면 로그인은 다시 해야 함

단축키

키 칸을 누르고 새 조합을 누르면 바로 바뀜. Ctrl·Alt·⌘ 중 하나는 같이 눌러야 함 (F1~F24는 단독 가능).

X 단축키 활성 패널에서

X가 원래 쓰는 키를 다른 키로 바꾸거나 끔. 바꾸면 원래 키는 안 먹음 (g → h 같은 연속키는 원래 키도 그대로 됨). 글 입력칸에서는 안 바뀜. X에 없는 키로 바꾸면 그 키의 X 기능은 가려짐.

알림 표시

안 읽은 알림·쪽지가 있으면 트레이 아이콘과 작업 표시줄 아이콘에 빨간 느낌표 (맥은 Dock·메뉴 막대에 숫자), 창 제목에 (3). 끄면 숫자는 상단 바와 트레이 툴팁에만 남음.

새 버전

GitHub에 새 버전이 올라오면 상단 바와 트레이 메뉴에 표시. 설치는 직접 (받기를 누르면 릴리스 페이지가 열림). 지금 버전

X 화면 규칙

다운 버튼·캡쳐·익명화·알림 숫자가 X 화면에서 게시물·이름·사진·배지를 찾는 규칙. X가 화면을 바꾸면 저장소의 규칙 파일만 고쳐서 새 버전 없이 따라감. 받는 건 선택자 문자열뿐이고, 받기 실패나 이상한 파일이면 앱에 든 규칙을 씀.
